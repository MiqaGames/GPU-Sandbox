# Instuction
В данной папке реализована работа с инструкциями и их исполнение.

## instruction.h

В этом файле происходит инициализация стуркутры инструкции, а так же опкодов (подробную информацию см. в документации).

### Примечание:
В данном файле есть коментарии, которые могут быть не верны на определённой стадии разработки программы, для получения точного объяснения следует обратиться к **документации**

## instuction.c

В данном файле реализована непосредственное исполнение программы: функция run, которая:
1. Находит опкод, с которым надо совершить операцию.
2. Проверяет с помощью чекеров на доступность и корректность ввода инструкции.
3. Исполнение кода.

### Чекеры

Помимо основной функции, в данном файле реализованы чекеры (checkers), которые проверят операнды на корректность вызова в текущем условии.
- destination\address register\source register\condition register\ target register - чекеры, которые проверяет регистр, на доступность к использованию. Их разница заключается в выводе определённого текста, в зависимости от ошибки.
- memory address - проверят на доступность ячейки памяти для использования (запеси, чтения данных)..
- instruction index - проверят на наличие инструкции с определённым индексом.

##### При увеличении количесвта чекеров, в будущей версии программы они могут быть вынесены в отдельный файл.
