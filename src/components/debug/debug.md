# Debug

В данной папке находяться функции для вывода текущего состояния программы 

## Core.h

Хранит в себе структуру функций для вывода состояния программы

## Core.c

Непостредственно исполняет их, а именно:
- print registers - выводит текущее состояние регистров
- print state - выводит текущее состояние ядра
- print programm - выводит инструкции, которые исполнила(-ит) программа.

##### В данной папке содержиться техническая информация, которая нужна исключительно для провеки логики программы и выявление ошибок на этапа работы с опокодами. В готов варианте она будет реализована по другому. #####
