# Config Decoder

Модуль `config_decoder` отвечает за загрузку, парсинг и проверку конфигурации симулятора кэша из JSON-файла. Он используется для чтения параметров кэш-памяти уровня L1 и L2, преобразования их в структурированные данные и проверки корректности перед дальнейшей работой в системе.

## Цель модуля

Модуль позволяет:

- прочитать конфигурацию из файла;
- распарсить JSON-структуру;
- извлечь параметры кэша для уровней `l1` и `l2`;
- проверить соответствие формату и допустимым значениям;
- вернуть результат в виде структуры `SimulatorConfig`.

---

## Используемые структуры

### `CacheConfig`

```c
typedef struct {
    size_t sets;
    size_t ways;
    size_t words_per_line;
} CacheConfig;
```

Эта структура хранит параметры одного уровня кэша:

- `sets` — количество наборов (set count);
- `ways` — количество способов ассоциативности (ways);
- `words_per_line` — количество слов в строке кэша.

### `SimulatorConfig`

```c
typedef struct {
    CacheConfig l1;
    CacheConfig l2;
} SimulatorConfig;
```

Здесь хранятся параметры двух уровней памяти:

- `l1` — конфигурация первого уровня кэша;
- `l2` — конфигурация второго уровня кэша.




## Публичные функции

### `bool config_load_file(const char *path, SimulatorConfig *config, char *error, size_t error_size)`

Эта функция загружает конфигурацию напрямую из файла на диске.

#### Что она делает

1. Проверяет корректность входных аргументов:
   - `path` не должен быть `NULL`;
   - `config` не должен быть `NULL`;
   - `error` и `error_size` должны быть корректно переданы.
2. Открывает файл в режиме бинарного чтения (`"rb"`).
3. Определяет размер файла с помощью `fseek()` и `ftell()`.
4. Проверяет, что файл не пустой и доступен для чтения.
5. Выделяет память под содержимое файла плюс нулевой символ.
6. Читает содержимое файла в буфер.
7. Завершает чтение файла и вызывает `config_parse_json()`.
8. Освобождает выделенную память и возвращает результат.
---

### `bool config_parse_json(const char *json_text, SimulatorConfig *config, char *error, size_t error_size)`

Эта функция принимает строку с JSON и превращает её в структуру `SimulatorConfig`.

#### Что она делает

1. Проверяет корректность аргументов.
2. Выполняет разбор JSON через `cJSON_Parse()`.
3. Получает значения:
   - `version`;
   - `cache`.
4. Создаёт переменную `parsed` типа `SimulatorConfig` и обнуляет её.
5. Читает параметры для `l1` и `l2` через вспомогательную функцию `read_cache_config()`.
6. Проверяет корректность обеих конфигураций через `validate_cache_config()`.
7. Если всё корректно, копирует результат в `*config` и возвращает `true`.
8. Если одна из конфигураций не проходит валидацию, возвращает `false`.

---

### `bool get_memory_size(const cJSON *parent, size_t *memory_size, char *error, size_t error_size)`

Эта функция извлекает размер памяти из JSON-объекта.

#### Что она делает
1. Проверяет, что `parent` и `memory_size` не равны `NULL`.
2. Находит объект `memory` в JSON.
3. Проверяет, что объект `memory` существует и является объектом JSON.
4. Извлекает поле `size` и проверяет, что оно существует, является числом и больше нуля.
5. Преобразует значение в `size_t` и сохраняет в `*memory_size`.

## Внутренние служебные функции

### `static bool read_cache_config(const cJSON *parent, const char *name, CacheConfig *config)`

Это вспомогательная функция, которая извлекает параметры одного уровня кэша из объекта `cache`.

#### Как она работает

1. Проверяет, что `parent`, `name` и `config` не равны `NULL`.
2. Находит объект `cache[name]`, например `cache["l1"]` или `cache["l2"]`.
3. Убеждается, что это объект JSON, а не число, строка или массив.
4. Извлекает поля:
   - `sets`;
   - `ways`;
   - `words_per_line`.
5. Проверяет, что все поля существуют, являются числами и больше нуля.
6. Проверяет, что значения не выходят за пределы `size_t`.
7. Проверяет, что числа не являются дробными значениями (`1.5`, `2.7` и т.п.), так как поля должны быть целочисленными.
8. Преобразует значения в тип `size_t` и сохраняет в структуру `CacheConfig`.


---

### `static bool validate_cache_config(const CacheConfig *config)`

Это функция финальной валидации структуры кэша.

#### Что она проверяет

- указатель `config` не `NULL`;
- `sets != 0`;
- `ways >= 2`;
- `words_per_line != 0`.
