# Simulator
В данной папке реализована запуск программы, а именно чтение и выполнение инструкций.

## simulator.h

В нём инициализируются циклы, а так же их максимальное значение

## simulator.c

Тут происходит выполнение функции **run**, которая отвечает за исполнение инструкций, а именно:
- Краткий анализ на некорректно составленные инструкции.
- Изминеие текущего цикла
- Непосредственная передача значений инструкций для использования функцией *execute*
