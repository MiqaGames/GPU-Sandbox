# Simulator

Модуль симулирует тактовое выполнение задач на нескольких виртуальных ядрах. Планировщик выдаёт задачи в порядке входа в массив **Simulator.tasks**.

## simulator.h

`Program` содержит указатель на массив инструкций и его размер. `Task` хранит программу, начальные регистры, итоговый статус и статистику задачи. `CoreContext` хранит виртуальное ядро, статус занятости и индекс назначенной задачи. `Simulator` хранит массивы ядер и задач, количество элементов, индекс следующей задачи, общую память и число глобальных тактов.



## simulator.c

`run()` повторяет следующие действия до завершения всех задач или достижения **MAX_CYCLES**:

1. Назначает очередные задачи свободным ядрам.
2. Каждое занятое ядро выполняет не более одной инструкции за такт.
3. При завершении сохраняет результат в *Task*, затем освобождает контекст ядра.

Начальные значения регистров копируются из задачи после ***core_reset()***. Программа выбирается по индексу задачи, статистика операций ведётся отдельно для каждой задачи. Память общая для всех ядер; обращения в данной модели исполняются последовательно в порядке обхода ядер.

***step_core()*** проверяет допустимость *pc*, исполняет одну инструкцию через ***execute()*** и обновляет состояние задачи. ***find_free_core()*** ищет свободный контекст, а ***find_working_cores()*** проверяет наличие выполняющихся задач.

Таймаут относится ко всей симуляции. При достижении лимита активные задачи получают статус *TASK_TIMEOUT*, а состояние их виртуальных ядер становится *TIMEOUT*.
