# Core

Этот модуль описывает состояние и поведение виртуального процессорного ядра. Ядро хранит регистры, указатель команды, текущее состояние выполнения и флаг сравнения. Смысл этого модуля в том, чтобы представлять CPU в простом виде, чтобы симулятор мог исполнять инструкции без реального железа.

## Что хранится в ядре

### Core
Структура `Core` содержит:
- `registers[8]` — регистры общего назначения;
- `pc` — програмный счётчик, номер текущей инструкции;
- `current_state` — текущее состояние ядра;
- `flag` — результат сравнения из последней операции `CMP`.

### State
Состояние ядра может быть одним из следующих:
- `NORMAL` — выполнение идёт штатно;
- `JUMP` — была выполнена переходная инструкция;
- `HALT` — программа завершилась;
- `ERROR` — произошла ошибка выполнения;
- `TIMEOUT` — симуляция превысила лимит тактов.

### Flag
Флаг нужен для сравнения:
- `SAME` — значения равны;
- `GREATER` — первое значение больше второго;
- `LESS` — первое значение меньше второго.

## Зачем нужен этот модуль

Ядро — это контекст исполнения задачи. Оно хранит всё, что связано с вычислениями на данном виртуальном процессоре: значения регистров, текущее состояние и результат последнего сравнения. Без него нельзя корректно выполнять инструкцию `CMP`, а также невозможно отслеживать финиш программы или ошибку выполнения.

## Функции

### core_reset
Функция `core_reset(Core *core)` сбрасывает ядро в начальное состояние.

Что она делает:
- обнуляет все регистры;
- сбрасывает `pc` в `0`;
- устанавливает `current_state = NORMAL`;
- сбрасывает `flag = SAME`.

Это важно, потому что каждый новый task или новая задача в симуляторе должна стартовать "с чистого листа". Без этого после одной программы данные могли бы остаться в регистрах и исказить следующую.

## Почему это важный модуль

Ядро является основным контекстом исполнения. Все остальные модули — память, инструкции, кэши, симулятор — работают вокруг него. Именно через ядро происходит:
- чтение аргументов инструкций;
- запись в регистры;
- проверка состояний;
- принятие решения о переходах и завершении программы.

То есть ядро — это "память и состояние вычислителя" внутри виртуальной машины.
