# Memory
В данной папке реализована инициализация и базовые функции работы с памятью
## memory.h
В данном файле происходит непосредтвенная инициализация памяти и её размеров
## memory.c
Здесь реализованы базовые функции для работы с памятью, часть из которых задействуется в *instruction.c*.
- memory write - запись в ячейку памяти определённого значения
- memory read - получение значения из определённой ячейки памяти
- memory reset - обнуляет все значения в памяти до 0
