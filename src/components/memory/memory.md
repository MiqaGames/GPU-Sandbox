# Memory

Этот модуль реализует общую память симулятора. В проекте память — это массив из `uint32_t` длиной `MEMORY_SIZE`, то есть она представляет собой линейное пространство адресов, в котором ядра и кэши могут читать и записывать значения.

## Что хранится в памяти

### Memory
Структура `Memory` выглядит так:
- `data[1024 * 1024]` — массив ячеек памяти.


## Функции

### memory_write
Функция `memory_write(Memory *memory, uint32_t address, uint32_t value)` записывает значение в ячейку памяти.

Что делает:
- проверяет, что адрес находится в допустимом диапазоне;
- если адрес корректен, записывает `value` в `memory->data[address]`.

Зачем это нужно:
- `STORE` должен сохранять результат вычисления в память;
- кэш также должен обновлять основную память при записи.

### memory_read
Функция `memory_read(const Memory *memory, uint32_t address)` возвращает значение из памяти по адресу.

Если адрес в пределах `MEMORY_SIZE`, она возвращает содержимое ячейки. Если адрес выходит за пределы, возвращает `0`.

Зачем это нужно:
- `LOAD` получает данные из памяти по адресу регистра;
- кэш при промахе читает блок из памяти через эти функции.

### memory_reset
Функция `memory_reset(Memory *memory)` полностью очищает память.

Что делает:
- проходит по всем ячейкам массива;
- выставляет `0` в каждую из них.

Это необходимо при старте новой симуляции или после завершения задачи, чтобы следующий сценарий не видел мусор от предыдущего запуска.
