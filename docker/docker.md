# Docker
Docker - устройство для удобной работы над проектом. Он нужен приемущественно:
- Если проект запускают на разных ОС
- Если в проекте много файлов

## Управление Докером:
1. Перейти в корень проекта
2. Просписать команду ***docker compose -f docker/docker-compose.yml up --build***
3. Чтобы выключить докер нужно прописать ***docker compose -f docker/docker-compose.yml down***

##### Данная инструкция может быть неверна на некоторых ОС, так как проверялась только на *Windows 11 AMD64*
